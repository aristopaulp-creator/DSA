# Data Structures and Algorithms (DSA)

This repository contains implementations of various Data Structures and Algorithms in C, C++, and Java.

## Structure

- **C Programs**: Array operations (search, insert, delete, sort).
- **Hashing**: Hash table and mapping techniques.
- **Java Collections Framework (JCF)**: Usage of standard Java collections (ArrayList, LinkedList, HashMap, etc.).
- **Patterns**: Pattern printing problems and solutions.
- **Problems**: Practice problem solutions.
- **Recursion**: Recursive problem solving and backtracking.
- **SLL**: Singly Linked List implementations and algorithms.
